## What I understood
### Database migration
- Database migration involves moving data from one database system or environment to another.
- This can be used for:
    - Upgrading database systems.
    - Moving data to the cloud for better scalability.
    - Consolidating multiple databases for efficiency.

### Version Control
- Version control for databases ensures seamless management of database schema and objects.
- Its essence lies in its ability to manage and track every modification made to a database's schema and associated data over time, facilitating a robust collaboration and deployment framework.

#### Key components of Database Version Control
- **Schema management:** Involves tracking ganges to table definitions, views, constraints, triggers, and stored procedures.
- **Data management:** Focuses on the versioning of the table contents.
- **Versioning strategies:** Encompasses state-based version control, which delcares the ideal database state, and migrations-based version control.
- **Tooling:** Offer specialized functionalities to address the needs of database version control.
